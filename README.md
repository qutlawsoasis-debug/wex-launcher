# Wex

The launcher for the Aura client and Aura-Pack (Minecraft 1.20.1 and 1.21.1, Fabric).

- `core/` — Rust: pack sync, Minecraft/Fabric/Java install, launch, accounts.
- `app/` — Tauri 2 shell.
- `ui/` — Svelte 5 + TypeScript interface, designed to Apple HIG / Liquid Glass.

Pack source: https://github.com/qutlawsoasis-debug/Aura-Pack (`manifest.json` for 1.20.1, `manifest-1.21.1.json`).
Client source: https://github.com/qutlawsoasis-debug/aura-client

The rules for contributors and agents are in AGENTS.md.
